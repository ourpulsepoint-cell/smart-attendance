Today

Keep this app open (or open it when you arrive). It checks your location while it is open.

1 · Places (geofences)

Tap the map to set the centre, then set the radius. Use one place per office, campus or building.

2 · Attendance times

Teachers set the class time here; office managers set duty hours. Attendance opens a little before the start time.

3 · People

You can also type people straight into the Users sheet (plain PINs are hashed on first login).

Card + face

For people without a smartphone. Put this phone/tablet at the gate or classroom door. Each person taps their NFC card (or shows the QR card), looks at the camera and blinks or turns their head when asked. A photo is kept as proof. People without an enrolled face type their PIN.

ID + PIN (fallback)

If someone forgot their card: they type their ID and PIN on this device. Location is taken from this device.

Roll call

Tick names by hand — useful for a class without phones or when the network is down.
